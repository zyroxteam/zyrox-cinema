# 🎬 ZYROX CINEMA

4D animated movie watch/download website UI — round ZYROX CINEMA logo, splash
screen, 3D tilt cards, particles, parallax hero, fake player + download demo.

## Run
```bash
node server.js          # ya PORT=3102 node server.js
```
Zero dependencies. `index.html` standalone bhi khulta hai (browser me).

## Features
- **ZYROX CINEMA round logo** — 2 rotating gradient rings + glass core, header + splash
- **Splash screen** — spinning rings, shine sweep, name reveal, loading bar (tap to skip)
- **4D effects** — particles canvas, hero poster parallax, 3D tilt + glare cards, floating orbs, ring-pulse play buttons
- **Categories** — Bollywood, Hollywood, TV Shows, Web Series (nav tabs + sections + view all)
- **Watch** — movie modal with player (play/pause, seek, mute, buffering, progress)
- **Download** — 480p/720p/1080p/4K quality buttons + download progress simulation
- **Marquee** — "Made By Arjun Rajput" + **Footer** — "Developed by Zyrox Arjun Rajput"
